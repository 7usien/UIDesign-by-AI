# Arabic RTL craft

Arabic is a composed experience, not an automatic CSS mirror. Test line breaks, punctuation, numerals, controls, chronology, media crop, and mixed-language labels in actual RTL screenshots. Preserve semantic order: do not reverse timelines, code, financial signs, or product causality merely because the page direction is RTL.

For motion, avoid character splitting that damages Arabic shaping. Use word, line, or container transitions and provide an equally meaningful static reduced-motion state. Keep focus visible and controls usable at mobile widths and with 200% zoom.
