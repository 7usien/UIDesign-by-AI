# Reference Intelligence

Use references as evidence about desired qualities, not as templates.

## Deconstruct each source

Record:

- attention sequence and page rhythm;
- grid, asymmetry, density, and whitespace behavior;
- typography roles, scale contrast, and line length;
- image, illustration, product UI, or data role;
- color and material logic;
- interaction and motion purpose;
- conversion structure and proof placement;
- what is distinctive versus merely fashionable.

For every source, state `adapt`, `avoid`, and `transform`. Never copy its brand identifiers, wording, signature artwork, exact composition, or complete section order.

## Research beyond supplied references

When browsing is available and the user permits research, find a small set of current references relevant to the product category, audience expectation, content type, and technical constraints. Prefer live working sites and original sources. Do not browse component galleries merely to collect effects.

Use no more than five strong references. More sources usually dilute the direction.

## Synthesize, do not average

Combine references into one original grammar:

- one structural principle;
- one typographic principle;
- one proof/presentation principle;
- one interaction principle;
- explicit elements that must not carry over.

Resolve conflicts in this order: truthfulness, audience fit, comprehension, proof, accessibility, brand distinction, then novelty.
