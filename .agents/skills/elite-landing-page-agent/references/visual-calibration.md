# Visual calibration

Score rendered evidence, not intent or source code. After a revision, compare the same locale, viewport, direction, and motion state before and after. Record one concrete criterion, visible evidence, and `improved`, `unchanged`, or `regressed`.

Reject a release when a revision regresses first-screen CTA visibility, offer comprehension, proof truthfulness, RTL composition, reduced-motion meaning, or introduces a generic template signal. An unchanged result is not a premium improvement; it is acceptable only when it resolves a non-visual defect without weakening the page.

Calibration cases are guardrails, not templates. Review them blindly: do not expose builder rationale or model identity to the critic.
